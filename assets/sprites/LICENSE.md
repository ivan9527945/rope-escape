# Sprite art

All images in this folder are original pixel art generated for Rope Escape by
`tool/gen_sprites.py` (skylines, façade tiles, roof trim, steel truss, airship,
air-conditioner and fire-escape silhouettes). The climber itself is drawn in
code (`lib/render/climber.dart`). No third-party game assets are used.
